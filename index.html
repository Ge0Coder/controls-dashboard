Today's Knowledge Bite

The Schneider Modicon switch advisory traces back to Blast-RADIUS, an MD5 chosen-prefix collision attack against the 1991-era RADIUS authentication protocol that is still embedded in countless industrial switches, firewalls, and remote access servers. Despite being known as cryptographically weak for over two decades, RADIUS/UDP with MD5 remained the default in OT gear because it 'just worked' — a perfect example of how protocol inertia in industrial networks can outlive several generations of cryptographic best practice.

Engineering Curiosity

⚛

The PID controller predates electronics by decades. Elmer Sperry's ship's gyrocompass autopilot of 1911 already used proportional, derivative, and crude integral action — implemented with mechanical levers, springs, and gear trains driving a hydraulic ram on the rudder. Nicholas Minorsky formalised the math in 1922 by carefully watching how a helmsman actually steered, observing that good helmsmen instinctively added derivative anticipation and integral bias-correction to their proportional response — meaning the canonical control algorithm of modern industry was first reverse-engineered from human behaviour, not derived from theory.

Tech Spotlight

OPC UA over Time-Sensitive Networking (TSN) is finally moving from demonstrations to pilot deployments in 2026. The combination promises deterministic, bounded-latency communication on standard Ethernet — meaning motion control, safety, and process data can share the same wire that carries MES traffic, without the jitter that historically forced engineers to deploy separate Profinet IRT, EtherCAT, or Sercos networks. The practical implications are significant. A single converged network reduces cable runs, simplifies spares, and lets you apply standard IT security tooling (segmentation, monitoring, NDR) to traffic that used to live on proprietary, opaque buses. OPC UA PubSub over TSN also enables many-to-many communication patterns that classic client/server OPC could not handle at control-loop rates. Adoption challenges remain real. TSN requires switches that support IEEE 802.1Qbv (time-aware shaping), 802.1AS (precision timing), and a central network configurator — and not all 'TSN-capable' switches implement the same profile. Toolchains for configuring traffic schedules across multi-vendor estates are immature, and most field devices still lag the controller and switch ecosystem. Expect the next 18 months to focus on the IEC/IEEE 60802 industrial profile, which should finally pin down interoperability.Read more →

Standards Watch

IEC 62443 continues its steady expansion. IEC 62443-2-1 (security program requirements for asset owners) reached its updated edition last year, and asset owners are now wrestling with how to map their existing CSMS documentation onto the revised structure, which aligns more cleanly with the zones-and-conduits language in 62443-3-2. If you have not already, this is the year to redo your high-level risk assessment using the formal SL-T (target security level) methodology rather than the informal scoring many sites adopted a decade ago. On the product side, more vendors are achieving IEC 62443-4-1 (secure development lifecycle) and 4-2 (component requirements) certifications — and increasingly procurement teams are demanding evidence. The Schneider, Siemens, and Hitachi advisories this week are useful test cases: certified products still ship with vulnerabilities, but the disclosure cadence, CSAF machine-readable advisories, and clearly documented mitigations are direct outputs of 4-1 conformance. NIST CSF 2.0 adoption in OT environments continues to grow, particularly the new Govern function, which finally gives plant managers a structured way to articulate cybersecurity accountability up to the board. For US critical infrastructure, expect TSA and EPA sector-specific guidance to keep converging on a CSF + 62443 hybrid baseline rather than picking one or the other.Read more →

Incident of the Week

This week's reflection is on the ongoing TeamPCP supply-chain campaign that SANS ISC continues to track, with formal US government engagement now confirmed. The campaign weaponised legitimate security scanners and developer tooling, turning trusted update channels into delivery mechanisms for credential-harvesting payloads. Several recent KEV entries — the Nx Console and TanStack npm package compromises — share the same pattern: malicious code published under a trusted identity. What makes this relevant to controls engineers is that engineering workstations are increasingly hybrid machines. They run vendor programming software alongside Python, Node.js, Git, and developer extensions for tasks like generating PLC tag CSVs, parsing trends, or building HMI graphics. Each of those package ecosystems is now a viable entry path into a workstation that also has authenticated access to live controllers. Three lessons. First, engineering workstations should have a tightly controlled software baseline — no ad-hoc npm or pip installs from the internet. Second, programming software should never run on a workstation that also has general-purpose internet browsing or developer toolchains; the airgap-by-policy approach using dedicated EWS hardware still pays off. Third, if you must use modern dev tooling on the OT side, run it inside a VM or container that cannot reach controllers directly, and use a mediated jump path with logging for any actual download to a PLC or DCS.Read more →

ICS / OT News Digest

This week's ICS Patch Tuesday is substantial. CISA published advisories covering Schneider Electric Modicon Network Managed Switches (RADIUS protocol forgery risk, related to the broader Blast-RADIUS class of issues), Schneider EcoStruxure Panel Server (unauthorized authentication), Siemens KACO Blueplanet inverters (credentials derivable from serial numbers — a recurring weakness in DER equipment), Hitachi Energy MACH HiDraw (buffer overflow with potential RCE), and Hitachi Energy RTU500 (availability-focused issues with secondary confidentiality and integrity impact). For maritime operators, NAVTOR NavBox 4.16.1.20 carries hard-coded credentials (CVE-2026-21404). Plant engineers should prioritise the RTU500 and Modicon switch advisories given their prevalence in substation and plant networks. On the IT side that bleeds into OT, Microsoft issued ~200 patches with 38 critical and three publicly disclosed pre-release; Adobe shipped 123 fixes (heavy on Experience Manager). Fortinet and Ivanti both patched unauthenticated remote OS command injection flaws — classic perimeter-appliance issues that often serve as the pivot point into segmented OT networks. ServiceNow quietly patched an actively exploited flaw it had known about since April 7, which raises questions for asset owners relying on ServiceNow for CMDB or OT workflow integration. The standout is Arista's announcement that CVE-2026-7473 — an incomplete tunnel decapsulation comparison in EOS being actively exploited — will not receive a patch. Affected sites must apply vendor mitigations or retire the gear. Many process plants use Arista in their L2/L3 aggregation between control rooms and DMZs, so review your fleet against the advisory immediately. Rockwell Automation announced enhancements to its SecureOT offering — worth a look if you are evaluating managed OT security services, though details remain marketing-light. Finally, SANS continues to track the TeamPCP supply-chain campaign, which has now drawn formal US government attention; if you ingest third-party security scanners or developer tooling into engineering workstations, audit those pipelines.Read more →

CISA Vulnerability Digest

CISA added several entries to the KEV catalogue this week that matter for OT-adjacent infrastructure. CVE-2026-7473 (Arista EOS tunnel decapsulation) is the headline — actively exploited and unpatched, requiring mitigation or replacement. CVE-2026-50751 in Check Point Security Gateway is an IKEv1 authentication bypass with confirmed ransomware association, allowing unauthenticated VPN access; if Check Point gateways front your remote engineering access, patch and audit VPN logs urgently. CVE-2026-0257 (Palo Alto PAN-OS VPN auth bypass) and CVE-2024-21182 (Oracle WebLogic T3/IIOP) round out a clear theme: remote access infrastructure is the current battleground. Cisco Catalyst SD-WAN Manager (CVE-2026-20245) and SolarWinds Serv-U (CVE-2026-28318) are also actively exploited; both are commonly found bridging enterprise and OT environments. The older Linux kernel cgroups flaw (CVE-2022-0492) appearing now suggests attackers are finding it useful for container escapes on edge/industrial Linux hosts. For controls engineers, the practical action is to review every remote access path into your control system — VPN concentrators, jump hosts, SD-WAN edges — confirm patch state, enforce MFA, and verify that exposed management interfaces are not reachable from the internet or the corporate LAN without mediation.Read more →
