Today's Knowledge Bite

The Modbus protocol, still the lingua franca of industrial networks nearly 50 years after its 1979 release by Modicon, was originally designed to run at 9600 baud over RS-232 for a single PLC product line. Its function code structure — read coils, read holding registers, write single register — was never meant to scale, yet it now underlies billions of dollars of global production because nobody has successfully displaced it. Most 'modern' Modbus TCP implementations still carry the original 1-indexed register quirk and 253-byte PDU limit as artifacts of that serial origin.

Engineering Curiosity

⚛

The PID controller we all rely on predates electronic computing by nearly a century. Elmer Sperry's ship-steering gyrocompass autopilots of the 1910s used mechanical linkages to implement proportional-plus-derivative action, and the full three-term form was formalized by Nicolas Minorsky in 1922 while analyzing the USS New Mexico's steering behavior — he explicitly noted that a helmsman naturally responds not just to heading error but to its rate of change and its accumulated history. In other words, every tuning session you've ever done is really reverse-engineering what a good human helmsman did intuitively a hundred years ago.

Tech Spotlight

OPC UA over TSN (Time-Sensitive Networking) continues to move from pilot to early production in 2026, and it's worth understanding even if you're not deploying it yet. The idea is simple but powerful: combine OPC UA's semantic, secure, vendor-neutral data model with IEEE 802.1 TSN's deterministic Ethernet timing (sub-microsecond synchronization via 802.1AS, scheduled traffic via 802.1Qbv, and frame preemption via 802.1Qbu). The result is a single converged network that can carry motion-control-grade cyclic data, standard OPC UA PubSub telemetry, and regular IT traffic on the same wire without the usual VLAN gymnastics. For controls engineers, the practical pitch is replacing EtherCAT, PROFINET IRT, Sercos III, and Ethernet/IP CIP Motion with one standardized stack — meaning a Siemens drive, Rockwell PLC, and Beckhoff IPC could theoretically share deterministic traffic. Current adoption challenges remain significant: managed TSN switches cost 2-4x standard industrial Ethernet switches, configuration tooling via CNC (Centralized Network Configuration) is immature, and most installed field devices don't support TSN yet. Realistic near-term use is new greenfield lines or semiconductor/battery megafactories where the convergence benefits justify the cost, not retrofits of existing plants.Read more →

Standards Watch

IEC 62443-4-2, which specifies technical security requirements for IEC components (embedded devices, host devices, network devices, and software applications), continues to be the reference point most product vendors are now certifying against. If you're evaluating new PLCs, RTUs, or industrial switches, asking for 62443-4-2 Security Level 2 certification at minimum is becoming standard practice in utility and pharma procurement. The spec maps cleanly onto the kinds of vulnerabilities disclosed today — the Danfoss stack overflow, for instance, would fail multiple Component Requirements (CR 3.5 input validation, CR 7.2 resource management) at any SL. On the US side, NIST SP 800-82 Rev. 3, released in 2023, remains the baseline for OT security program design and is heavily referenced in CISA's Cross-Sector Cybersecurity Performance Goals (CPGs). Worth noting is the increasing alignment between 800-82r3 and the NIST Cybersecurity Framework 2.0, which added the Govern function — practically, this means boards and executives are starting to ask OT teams about governance artifacts (policies, risk acceptance, supplier management) that previously only lived in IT. If you haven't already, map your plant's OT security practices to the CSF 2.0 Govern subcategories; it's the question auditors will ask next.Read more →

Incident of the Week

A useful case to revisit this week is the 2021 Oldsmar, Florida water treatment incident, which has been re-examined in several recent post-mortems as the industry reassesses what actually happened. An operator noticed the mouse cursor move on an HMI and watched an unknown party raise the sodium hydroxide (lye) setpoint from 100 ppm to 11,100 ppm. The operator immediately reverted the setpoint, and downstream pH monitoring and finished-water sampling would likely have caught the change before any public harm — but the incident catalyzed widespread water sector investment in OT security. The root cause was a shared TeamViewer instance with a reused password, reachable from the public internet, on a Windows 7 engineering workstation. There was no MFA, no jump host, and no session logging. Recent analyses suggest the 'attacker' may have been a disgruntled insider or even an accidental misclick rather than a nation-state, which if anything reinforces the lessons: remove all unsanctioned remote access tools, enforce MFA and a hardened jump host for any legitimate remote engineering, and — critically — don't rely on the HMI alone as a safety layer. Independent instrumented protective functions, alarm rationalization, and finished-product monitoring did and still do the real work of protecting the public.Read more →

ICS / OT News Digest

CISA issued a cluster of ICS advisories today with direct relevance to plant floor engineers. The most severe is a stack-based buffer overflow in Danfoss AK-SM 8xxA refrigeration system managers (CVSS 9.8, CVE-2026-129713) allowing arbitrary code execution with webserver privileges — a serious concern for cold-chain, food, and pharma sites where these controllers are commonly internet-adjacent. AutomationDirect's C-More EA9 programming software (≤V6.80) has a file-parsing memory corruption flaw that could lead to code execution if engineers open a malicious project file, reinforcing the need to treat .ea9 files from unknown sources as untrusted. Schneider Electric's EcoStruxure Power Build Rapsody switchboard design tool also has a memory corruption flaw via malicious project files. Two advisories stand out for their unusual scope. Autonomy Logic's OpenPLC Runtime (≤4.2.4) contains a race condition allowing creation of unauthenticated admin accounts — relevant to the growing number of educational, research, and small-system deployments using OpenPLC. Elecbrakes trailer brake controllers (EB2, VM1, ELBC2000) have vulnerabilities allowing remote takeover of trailer brakes, firmware modification, and disabling of safety features; while automotive-adjacent, it illustrates the expanding attack surface of safety-critical embedded controllers. A libumqtt integer underflow (CVE-2026-125132) matters because this MQTT client library ships inside many IIoT gateways and edge devices. On the enterprise side with OT implications, GeoServer is under active exploitation via two newly disclosed high-severity flaws — notable because GeoServer is widely deployed in utilities, pipelines, and transportation for GIS-backed asset management. The US Treasury's FinCEN has disconnected systems after a cyber incident, and ShinyHunters claims a comeback, both reminders that enterprise IT disruption frequently cascades into OT scheduling, logistics, and compliance reporting. Engineers should verify whether any site-level historians, MES, or ERP integrations traverse affected vendor platforms.Read more →

CISA Vulnerability Digest

CISA added a heavy batch of KEV entries over the past week. Most directly relevant to OT environments is CVE-2026-103406 in HPE Juniper Session Smart Conductor and Routers — an OS command injection as root via crafted salt minion IDs. Session Smart is widely deployed in SD-WAN overlays that increasingly connect remote substations, pumping stations, and process plants back to central SCADA; patch immediately and audit salt-minion exposure. CVE-2026-123890 in Broadcom VMware vCenter is an authentication bypass via the Directory Service, significant because vCenter typically hosts virtualized historians, HMI servers, and engineering workstations in Purdue Level 3 environments. Also noteworthy: CVE-2026-123039 in Check Point products (DynamicCLI daemon permissions), CVE-2026-76466 hard-coded credentials in Cisco Expressway, and CVE-2026-115731 Puppet Enterprise deserialization — all common infrastructure in industrial DMZs. The Drupal Core installer flaw (CVE-2026-132165) and Apache Axis unsafe reflection (CVE-2026-90436) affect legacy portals still present at many utility and manufacturing sites. For OT teams, the priority order should be: internet-facing SD-WAN routers, vCenter instances hosting OT workloads, then DMZ web services. Verify your asset inventory covers these, because KEV additions carry a federal 21-day remediation deadline and are strong indicators of active exploitation in the wild.Read more →
