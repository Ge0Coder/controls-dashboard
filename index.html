Today's Fact

The FragAttacks vulnerabilities surfacing in this week's SCALANCE advisory (CVE-2020-24588 and friends) are design flaws in the 802.11 standard itself, not bugs in a specific vendor's code — meaning every Wi-Fi chipset ever made is affected to some degree. One of them, the aggregation attack, exploits a single unauthenticated bit in the frame header that tells the receiver whether the payload is an A-MSDU or a regular frame, letting an attacker smuggle arbitrary packets into an encrypted WPA2/WPA3 session. That's why industrial wireless gear keeps getting re-patched for these six-year-old CVEs: the fix lives in firmware, not in the protocol.

ICS / OT News Digest

CISA published a heavy slate of ICS advisories this week, with Siemens dominating the list. Siemens Industrial Edge Management has an authorization bypass that lets an unauthenticated remote attacker slip past authentication and reach connected Edge devices via the remote connection feature — a serious concern for anyone using IEM to manage distributed edge compute at the plant. SINEC NMS (pre-V4.0 SP3) has a similar authorization bypass that allows arbitrary account password resets, and RUGGEDCOM CROSSBOW Station Access Controller carries a code execution and DoS flaw. SCALANCE W-700 802.11n wireless APs are affected by the older FragAttacks family (CVE-2020-24588 and related), fixed in firmware 6.6.0 — worth planning into wireless maintenance windows for any cell/area networks relying on them.

On the field-device side, SenseLive X3050 Modbus gateways (V1.523) have eleven new CVEs that collectively allow complete device takeover; these gateways often sit directly on RS-485 loops bridging meters and sensors to TCP, so exposure should be audited immediately. Silex Technology SD-330AC industrial wireless clients and the AMC Manager platform also have multiple flaws permitting unauthenticated code execution, DoS, and configuration tampering — a reminder that wireless bridge hardware is frequently forgotten during patch cycles.

Beyond advisories, SecurityWeek reports a new wiper dubbed Lotus Wiper that targeted the Venezuelan energy sector before recent US intervention, specifically attacking recovery mechanisms and systematically deleting files — a textbook destructive OT playbook worth reviewing against your own backup isolation and recovery drills. The UK's cyber chief warned that Russia, Iran, and China pose the most serious threats and that British industry should expect to be targeted at scale in any conflict escalation. A Mirai variant is also now exploiting a year-old flaw in discontinued D-Link routers, which occasionally end up in small remote sites or contractor networks bridging into OT.

For the supply-chain-minded, SecurityWeek's piece on SBOMs argues that raw SBOM and VEX data aren't translating into actionable defense without a governance-driven intelligence layer — relevant for controls teams being asked to consume SBOMs from vendors like Rockwell, Siemens, and Schneider without the tooling to act on them. SANS ISC also published a useful piece on using EPSS to triage the daily CVE flood, which is a practical approach when you're juggling IT and OT patch queues with very different risk profiles.

CISA Vulnerability Digest

The most OT-relevant KEV additions this period are the three Cisco Catalyst SD-WAN Manager entries (CVE-2026-20122, 20128, 20133), covering malicious file upload via the API, recoverable credential storage, and sensitive-information exposure. SD-WAN Manager is increasingly used to stitch together remote sites, substations, and plants, so compromise here can expose the management plane for an entire WAN fabric — prioritize patching and verify that the management interface is not reachable from process networks. Fortinet FortiClient EMS (CVE-2026-21643) SQL injection and Ivanti EPMM (CVE-2026-1340) unauthenticated RCE are both being actively exploited and commonly appear on engineering laptops and mobile HMIs that roam between corporate and OT zones.

Several Microsoft entries are worth flagging for engineering workstations: a Defender privilege escalation (CVE-2026-33825), a SharePoint spoofing flaw (CVE-2026-32201) which matters if SharePoint hosts P&IDs or procedures, plus older but freshly-KEV-listed Office/Excel (CVE-2009-0238) and VBA (CVE-2012-1854) RCEs — a reminder that legacy Office macros are still a viable entry vector onto engineering PCs that open vendor-supplied spreadsheets. Apache ActiveMQ (CVE-2026-34197) code injection is also relevant where ActiveMQ is embedded in historian or MES middleware.

Practical remediation: patch internet-exposed management tools (SD-WAN Manager, EPMM, FortiClient EMS) first, enforce MFA on those consoles, block OT-to-Internet egress from engineering workstations, and audit any SharePoint, ActiveMQ, or Exchange instances that touch the Purdue Level 3/3.5 boundary.
