Today's Knowledge Bite

The Ruggedcom line Siemens just patched traces back to a Canadian company founded by ex-Nortel engineers specifically to build Ethernet switches that could survive substation electromagnetic transients — IEEE 1613 and IEC 61850-3 environments where ordinary switches fail within months. Siemens acquired them in 2013, and the ROX (Rugged Operating System on Linux) firmware is essentially a hardened Debian variant. That Linux heritage is exactly why these devices inherit third-party CVEs like the 2019 batch just disclosed.

Engineering Curiosity

⚛

The PID controller predates electronics entirely. Elmer Sperry's gyroscopic ship autopilots in 1911 implemented proportional-plus-derivative control mechanically using flyweights and dashpots, and by 1922 Nicolas Minorsky had formalised the full three-term algorithm by mathematically analysing how a helmsman actually steered the USS New Mexico. The integral term was inspired by watching humans gradually correct for steady cross-winds — meaning the I in PID is essentially a model of human stubbornness, captured in differential equations a century before anyone wrote a function block.

Tech Spotlight

OPC UA FX (Field eXchange) is quietly maturing into the technology that may finally unify controller-to-controller communication across vendors. Released by the OPC Foundation as a companion specification, FX extends OPC UA PubSub down to the field level with deterministic behaviour over TSN (Time-Sensitive Networking), targeting the same use cases historically served by EtherNet/IP, PROFINET IRT, and EtherCAT — but vendor-neutral. For a controls engineer, the practical promise is that a Beckhoff PLC, a Siemens S7-1500, and a Rockwell ControlLogix could exchange tags directly with shared semantic models, without gateways or tag-mapping spreadsheets. The information model carries engineering units, ranges, and safety state intrinsically, which collapses a lot of integration work. Adoption is still early. The 2024 demos at Hannover Messe showed cross-vendor FX working, but real deployments are rare because TSN switches remain expensive, IT departments are unfamiliar with the configuration model, and most installed PLCs need firmware updates or new hardware to support PubSub at deterministic cycle times. Expect the first serious greenfield projects in automotive and semiconductor fabs over the next 18 months before it filters into general process industries.Read more →

Standards Watch

IEC 62443-3-2 (security risk assessment for system design) and 62443-2-1 (security program requirements for asset owners) continue to be the two parts most asset owners stumble on during certification. The recent revision of 62443-2-1, published in 2024, restructured the requirements around a clearer maturity model aligned with 62443-4-1 development practices, which means asset owners and product suppliers now speak a more compatible language when defining shared responsibility for patching and incident response. Worth watching: the ISA/IEC 62443-6-2 work on security evaluation methodology for IACS components is progressing, which will eventually give procurement teams a defensible way to compare vendor cybersecurity claims. In parallel, NIST released updates to SP 800-82 Rev. 3 guidance refinements addressing cloud-connected OT and remote engineering access — useful reading if you're being asked to justify cloud historian or remote support architectures. On the regulatory side, the EU Cyber Resilience Act (CRA) obligations begin biting in late 2027, and Siemens' aggressive advisory cadence (like this week's volume) is partly preparation: manufacturers must disclose vulnerabilities within 24 hours of awareness and provide security updates throughout the product's expected lifetime. Expect every major automation vendor to follow suit, which means more advisories to triage, not fewer.Read more →

Incident of the Week

In late 2023, a small municipal water utility in Aliquippa, Pennsylvania had a Unitronics Vision-series PLC compromised by an Iran-affiliated group calling itself CyberAv3ngers. The attackers defaced the HMI screen with anti-Israel messaging and forced the booster station into manual operation. No water quality impact occurred, but the incident triggered a CISA advisory and a wave of similar compromises at other small utilities running the same PLCs. The root cause was painfully simple: the Unitronics PLCs were directly exposed to the internet on TCP/20256 with the default password '1111'. The attackers didn't exploit a vulnerability — they logged in. CISA's subsequent scans found hundreds of similar devices exposed across US water and wastewater systems. Lessons for controls engineers: first, no PLC should ever be directly internet-reachable, regardless of how convenient remote programming is; put it behind a VPN with MFA. Second, default credentials on field devices are still the single highest-yield attack vector in OT — audit every controller, drive, and HMI you commissioned, not just the ones IT knows about. Third, small utilities and remote sites are disproportionately targeted precisely because they lack dedicated OT security staff; if you support multiple sites, build a standard hardening checklist and enforce it as part of commissioning sign-off.Read more →

ICS / OT News Digest

CISA published a substantial batch of Siemens advisories this week that demand attention from plant-floor teams. The most serious is a pair of Ruggedcom ROX flaws: an input validation bug in the Scheduler that lets an authenticated remote attacker run arbitrary commands as root, and an improper access control issue allowing arbitrary file reads with root privileges. A separate advisory covers a backlog of older third-party CVEs (2019 vintage) bundled into ROX firmware. All are fixed in ROX 2.17.1, and given that these are hardened substation/industrial routers often sitting at network boundaries, they deserve priority patching. Siemens also disclosed a denial-of-service vulnerability affecting a broad family of industrial devices, a SIMATIC HMI Unified Comfort Panels flaw (pre-V21.0) where the help link allows an unauthenticated attacker to reach the underlying web browser and pivot around Control Panel restrictions, and multiple Teamcenter vulnerabilities affecting confidentiality, integrity, and availability. Engineers running Unified Comfort Panels at machine level should validate kiosk lockdown is configured and consider Siemens' interim mitigations until firmware can be updated. On the IT side that bleeds into OT, exploitation of the critical NGINX vulnerability has begun, with PoC code now public. Default configurations are exposed to DoS, and if ASLR is disabled (common on appliances and some embedded gateways) remote code execution is possible. Many SCADA historians, MES front-ends, and remote access portals proxy through NGINX — check vendor advisories. Grafana confirmed a breach by the Coinbase Cartel group; Grafana dashboards are increasingly common for OT data visualisation, so review API token rotation and any pipelines that pull from cloud Grafana tenants. Finally, a researcher published the MiniPlasma exploit reusing 2020 PoC code against an unpatched Windows CVE, a reminder that engineering workstations running older Windows builds remain low-hanging fruit. Pwn2Own Berlin 2026 paid out $1.3M for fresh exploits across Windows, Linux, VMware, and Nvidia — patches will follow shortly and should be tracked for any virtualised OT infrastructure.Read more →
